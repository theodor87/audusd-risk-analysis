# AUD/USD Asset Drawdown & Risk Analysis

A Python-based quantitative analysis tool for tracking historical asset drawdowns, price corrections, and peak-to-trough metrics on the AUD/USD currency pair using Pandas and Matplotlib.

## Overview
This project fetches 1-year historical time-series data for the AUD/USD currency pair, computes running maximum peaks, calculates drawdown percentages, and visualizes market corrections cleanly to assess downside volatility.

## Technologies Used
* **Python**
* **Pandas** (Data manipulation & time-series analysis)
* **YFinance** (Financial data extraction)
* **Matplotlib** (Professional data visualization)

## Output Example
The script generates a two-panel professional chart showcasing price action with peak tracking alongside the corresponding drawdown and correction curve.
